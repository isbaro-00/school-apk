# Android / Flutter build

This project contains the Flutter/Dart source and Supabase integration. The Android platform folder is intentionally generated by the Flutter SDK rather than hand-copied, so the installed Flutter version supplies the matching Gradle/Android template.

## 1. Generate Android files

From the project root:

```bash
flutter create . --platforms=android --org=com.schoolmanagement
flutter pub get
```

Or use:

- Linux/macOS: `scripts/bootstrap_android.sh`
- Windows: `scripts/bootstrap_android.bat`

## 2. Build a debug APK

```bash
flutter build apk --debug \
  --dart-define=SUPABASE_URL=https://yeqpkotyeqvajxanlzpj.supabase.co \
  --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

## 3. Build a release APK

```bash
flutter build apk --release \
  --dart-define=SUPABASE_URL=https://yeqpkotyeqvajxanlzpj.supabase.co \
  --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

For Play Store distribution, use a signed app bundle:

```bash
flutter build appbundle --release \
  --dart-define=SUPABASE_URL=https://yeqpkotyeqvajxanlzpj.supabase.co \
  --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

## Security

- The Supabase publishable key is intended for the client and is supplied at build/run time.
- **Never put the Supabase service-role/secret key in Flutter/Dart, Android resources, or an APK.**
- Keep service-role/secret credentials only in server-side Edge Functions or another trusted backend environment.

## Important current state

The database and Edge Function work completed so far is included in this project. A live end-to-end production test has not been performed from this environment because Flutter/Android SDK and outbound Supabase network access are unavailable here.

The earlier SQL test using a direct SQL Editor insert into `students` hit the database's `validate_school_access()` trigger. Do not disable that trigger just to make the test pass; it is part of school-isolation security.
