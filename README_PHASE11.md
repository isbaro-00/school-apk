# Phase 11 — Exams & Results

Added:
- Exams dashboard
- Create exam
- Exam code display
- Exam profile
- Exam subject display
- Result service
- Marks entry foundation
- Automatic grade calculation in Flutter for the basic A-F scale

Database tables expected:
- exams
- exam_subjects
- results
- students
- subjects

Important:
1. The exact grading rules should eventually come from the school's grading settings/database rather than being hard-coded.
2. The marks screen currently displays existing result rows. A complete production flow should select a class first, load its students, then create/update result rows.
3. The `results` upsert expects a unique constraint on:
   exam_id, exam_subject_id, student_id
   Change `onConflict` if the executed SQL uses a different constraint.
4. Database/RLS remains the authority for school isolation.
5. Exam code should be generated by the database, not Flutter.
