# Phase 7 — Parents Module

Added:
- Parents list
- Add parent form
- Database-generated parent_code
- Parent profile
- Parent children list through student_parents
- Link-child service method

Database expectations:
- parents: id, school_id, parent_code, first_name, last_name, phone, email, status, created_at
- student_parents: parent_id, student_id
- students: id, admission_number, first_name, last_name, gender, date_of_birth, status, class_id

Security:
- school_id is supplied by the current authenticated user's school context.
- Database RLS must remain the authority for school isolation.
- parent_code is generated by the database, not Flutter.

This phase does not yet add a UI for linking a child to a parent. That can be added after the core parent module is integrated.
